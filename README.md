# My-MicroPad

I made a 3X3 based 9 switch Micropad for myself . It is based on Arduino Pro Micro and has diodes to prevention ghosting . I made thePCB on Kicad and the 3D CAD on fuion 360.

## Features
 - Based on Arduino Pro Micro
 - USB-B Type for Connection
 - Ghosting prevention
